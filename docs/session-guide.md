# 场次配置 · 使用说明（六表版）

> 主框架（**v3.0 四层内核**、24 个 API、云端两表、SEA 打包链）**完全不变**。
> 换主题 / 单位 / 学校 / 专业 / 名单 / 人数 / 题库，只改这一份 Excel。
> 转换器 `工程源码\tools\build_session.py` 会**保留** `session.json` 里的安全 / 离线 / 题库策略配置块，
> 换场次不会把引擎参数重置为默认。兼容旧版三表模板。

## 换一场考试，三步

1. 打开 **`场次配置.xlsx`**，按下面六个 sheet 填写；
2. 双击 **`一键更新.bat`** —— 自动同步 `工程源码\` 与 `应用程序\` 两处的 `students.json` / `questions.json` / `session.json`；
3. 重启 **`应用程序\职业技能考试系统.exe`**（自动以独立窗口打开大屏）。

> 本轮云端冻结：正在刷题期间不要发布线上实例、不清云端、不动数据库；本地换场次只改本机文件。

## 六个 sheet 说明

### ① 场次信息（字段 / 值 / 说明）

| 字段 | 说明 |
|---|---|
| 系统标题 | 学员端 / 大屏 / 分享页标题 |
| 场次编号 | 归档标识，同时作为导出文件名前缀 |
| 考试日期 | YYYY-MM-DD，可空（定时门禁后续接入） |
| 开考时间 / 收卷时间 | HH:MM，可空（定时门禁后续接入） |
| 时长(秒) | 单次答题时长上限，默认 3600 |
| 及格线(%) | 大屏及格率统计口径 |
| 每人最多次数 | 重考次数由管理员人工把关 |
| 学员进入口令 / 管理端口令 | 管理端口令仅服务端使用，不下发前端 |
| 主题编号 | 对应「主题配置」表，T1~T5，默认 T2 |
| 备注 | 可选 |

### ② 单位信息（字段 / 值 / 说明）

项目单位、培训学校、专业/工种、主办单位、承办单位、班次名称、地区。
副标题由「项目单位 · 培训学校 · 专业/工种」自动拼接；主办/承办/地区仅台账留存。

### ③ 名单（序号 / 姓名 / 备注）

- 备用账号 `备用账号1`、`备用账号2` 由脚本自动追加，**不用填**；人数自动算。
- 不填编号、性别、班组等其他字段（现行身份以姓名为准）。
- 不允许重名；含「备用」「测试」字样的行自动跳过。

### ④ 题库（行序 = 判分顺序）

| 列 | 说明 |
|---|---|
| 题号 | 数字，唯一不重复 |
| 专业/工种 | 可选标签，便于混库分组；留空即可 |
| 分类 | 必填 |
| 题型 | 单选题 / 多选题 / 判断题（下拉选择） |
| 题干 / 选项A~D | 选择/多选必填 4 个选项 |
| 答案 | 单选填 `A`~`D`；多选填 `A,C`（逗号分隔，支持中文逗号）；判断填 `正确`/`错误` |
| 解析 | 必填，判分后展示给学员 |
| 难度 | 易 / 中 / 难（下拉选择） |
| 分值 | 可空，默认 1 分；当前按题计分，分值为后续加权预留 |

### ⑤ 主题配置（台账 + 预置）

预置 T1 政务深蓝、T2 护眼青绿（现行默认）、T3 暖橙家政、T4 暗夜霓虹、T5 素白纸卷；
主题编号、名称、主色、辅色、适用端、备注。新增主题在表尾追加一行即可。

### ⑥ 场次清单（台账，不参与生成）

场次编号、名称、考试日期、名单来源、题库来源、主题编号、状态。用于多场次归档查阅，不驱动本场考试生成。

## 红线（务必遵守）

- 题库的「行序」就是服务端判分顺序（`questionPolicy.shuffle=false` 时），不要排序、删行、插行。
- 判断题答案填 `正确` / `错误`；单选题填单个字母；多选题填 `A,C`。
- 换场次前**先导出 CSV / JSON 成绩，再备份本地 `data.json`**；云端 `exam_results` 的清理/分区另行确认，不在本轮操作。
- 不要用真实学员测试，只用 `备用账号1` / `备用账号2`；考试进行中不要点「清空」。
- 口令写在 Excel 里，随包分发时注意别外泄。

## 数据与配置边界

| 位置 | 作用 |
|---|---|
| `场次配置.xlsx` | 配置源（可变子项），**不是运行时数据库** |
| `session.json` / `students.json` / `questions.json` | 由 Excel 生成，exe 启动时加载 |
| 云端 `exam_results` / `exam_config` | 考试过程数据真值，不进 Excel |
| `data.json` / `audit.jsonl` | 本地离线备份（原子写）/ 操作审计 |

exe 优先读同目录下三份 JSON，读不到才用内嵌默认场次；日常换场次**不需要重新打包 exe**，只有改引擎代码才需重打。

## 首次使用 / 模板重建

```powershell
cd "工程源码"
python tools/build_session.py --init --force   # 从现有 JSON 反推重建六表模板
```

自检：`node tools\selftest_v3.mjs`（独立 3399 端口 + 临时 DATA_DIR，不碰线上数据）。
